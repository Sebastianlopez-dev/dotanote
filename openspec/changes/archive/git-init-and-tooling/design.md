# Design: Git Init & Tooling Foundation

## Technical Approach

Bootstrap version control and developer tooling with zero UI regression. Git init on `main`, flat ESLint with all rules as `warn`, Prettier without Tailwind class reordering, and Vitest reusing Vite path aliases. Migrate from npm to **pnpm** as package manager (faster installs, strict dependency resolution, disk-efficient hard links). One initial `pnpm format` pass normalizes quote style; thereafter `src/` remains byte-stable across all tooling commands.

## Architecture Decisions

| Decision | Option A | Option B | Choice | Rationale |
|---|---|---|---|---|
| ESLint severity | `warn` only | `error` for critical rules | **A** | R3 mandates zero `error` severity so `npm run lint` exits 0 on a clean codebase |
| Prettier + Tailwind | Install `prettier-plugin-tailwindcss` | Skip Tailwind plugin | **B** | R4, R5 — plugin reorders classes; skipping guarantees `backdrop-blur-xl` etc. remain untouched |
| React ESLint plugin | `eslint-plugin-react` + `globals` | Hooks-only (`eslint-plugin-react-hooks`) | **A** | R5 — `react/jsx-uses-react` prevents false `no-unused-vars` warnings on `import React` |
| Quote normalization | `singleQuote: true` (spec) | Match existing double quotes | **singleQuote** | R4 spec value; one-time format pass establishes baseline, then stable |
| Vitest globals | `globals: true` | `globals: false` | **true** | R4 spec; avoids `import { describe, it }` boilerplate in every test |
| Vite alias reuse | Reference existing `resolve.alias` | Redefine in `test.alias` | **Reuse** | R4 — guarantees `@/` resolves identically in source and tests |
| Package manager | npm (current) | pnpm | **pnpm** | Faster installs, strict dependency resolution prevents phantom imports, disk-efficient via hard links. pnpm already installed on system. |

## Data Flow

No runtime data flow — pure infrastructure.

## File Changes

| File | Action | Description |
|---|---|---|
| `.git/` | Create | `git init -b main`, add remote, initial commit |
| `.gitignore` | Modify | Already exists; ensure `.env*`, `dist/`, `node_modules/`, `coverage/` present |
| `eslint.config.js` | Create | Flat config: `@eslint/js`, `typescript-eslint`, `eslint-plugin-react`, `eslint-plugin-react-hooks`, `eslint-config-prettier` |
| `.prettierrc` | Create | `semi`, `singleQuote`, `trailingComma: "es5"`, `printWidth: 100` |
| `package.json` | Modify | Add 12 devDependencies; replace `lint` script, add `format`, `test`, `test:watch`, `type-check` |
| `vite.config.ts` | Modify | Merge `test: { environment: 'jsdom', globals: true, setupFiles: './src/test/setup.ts' }` into returned config object |
| `src/test/setup.ts` | Create | Imports `@testing-library/jest-dom` matchers for Vitest |
| `pnpm-lock.yaml` | Create | Generated by `pnpm install` — replaces `package-lock.json` |
| `package-lock.json` | Delete | Replaced by `pnpm-lock.yaml`. Only delete AFTER `pnpm install` succeeds and `pnpm-lock.yaml` is confirmed present. |

## Interfaces / Contracts

### `eslint.config.js`

```js
import js from '@eslint/js';
import ts from 'typescript-eslint';
import react from 'eslint-plugin-react';
import reactHooks from 'eslint-plugin-react-hooks';
import globals from 'globals';
import prettier from 'eslint-config-prettier';

function downgradeToWarn(config) {
  if (!config.rules) return config;
  const rules = {};
  for (const [key, value] of Object.entries(config.rules)) {
    rules[key] = value === 'error' || value === 2 ? 'warn' : value;
  }
  return { ...config, rules };
}

export default [
  { ignores: ['dist/', 'node_modules/', 'coverage/', '*.config.js'] },
  { files: ['src/**/*.{ts,tsx}'] },
  { languageOptions: { parserOptions: { project: true }, globals: globals.browser } },
  downgradeToWarn(js.configs.recommended),
  ...ts.configs.recommendedTypeChecked.map(downgradeToWarn),
  downgradeToWarn(react.configs.flat.recommended),
  downgradeToWarn(react.configs.flat['jsx-runtime']),
  downgradeToWarn(reactHooks.configs['recommended-latest']),
  prettier,
  {
    rules: {
      'react/react-in-jsx-scope': 'off',
      '@typescript-eslint/no-unused-vars': ['warn', { argsIgnorePattern: '^_', varsIgnorePattern: '^React$' }],
    },
  },
];
```

### `package.json` — scripts

```json
"scripts": {
  "dev": "vite --port=3000 --host=0.0.0.0",
  "build": "vite build",
  "preview": "vite preview",
  "clean": "rm -rf dist",
  "lint": "eslint src/",
  "format": "prettier --write src/",
  "test": "vitest run",
  "test:watch": "vitest",
  "type-check": "tsc --noEmit"
}
```

Note: scripts use the package name directly (`eslint`, `prettier`, `vitest`, `tsc`), not `pnpm run` — this is intentional. pnpm resolves local binaries automatically. User runs `pnpm lint`, `pnpm format`, `pnpm test`, etc.

## Testing Strategy

| Layer | What to Test | Approach |
|---|---|---|
| Integration | Tooling scripts | Run `pnpm lint`, `pnpm format`, `pnpm test` and assert exit code 0 |
| Integration | Alias resolution | One dummy test in `src/test/alias.test.tsx` imports `@/src/App` and verifies resolution |

## Migration / Rollout

1. `git init -b main`
2. Migrate to pnpm: delete `node_modules/`, run `pnpm install` (generates `pnpm-lock.yaml` from existing `package.json`)
3. Verify `pnpm-lock.yaml` exists and `pnpm dev` starts the app → **only then** delete `package-lock.json`
4. `pnpm add -D` all listed devDependencies
5. Create `.prettierrc`, `eslint.config.js`, `src/test/setup.ts`
6. Modify `package.json` scripts and `vite.config.ts`
7. Run `pnpm format` once to normalize quotes
8. Run `pnpm lint` — verify exit code 0
9. Run `pnpm test` — verify Vitest starts and passes
10. `git add -A && git commit -m "chore: init git and tooling foundation with pnpm"`
11. `git remote add origin https://github.com/Sebastianlopez-dev/dotanote.git && git push -u origin main`
